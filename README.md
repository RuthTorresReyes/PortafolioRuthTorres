## 🚀 Proyectos destacados

### 📊 Monitoreo Integral de la Producción Minera (Tableau)
Dashboard interactivo en Tableau que evalúa el riesgo operacional y la sostenibilidad ambiental de 2.000 minas en Chile, Perú y Bolivia, cruzando producción histórica (1986-2022), consumo de agua, emisiones de CO₂ y tipo de mineral. Diseñado para simular el caso de uso de una consultora minera, priorizando decisiones de inversión según sostenibilidad y riesgo.

**Tecnologías:** Tableau Public · Modelado de datos · Storytelling con datos
**Demo:** [Abrir Dashboard →](https://public.tableau.com/views/RUTHTORRES-ENTREGAFINAL/Principal?:showVizHome=no&:embed=true&:toolbar=no&:tabs=no)

### 📈 Análisis Minero en Excel — Producción, Costos y Sostenibilidad
Análisis avanzado sobre una base de 500 registros de operaciones mineras, resolviendo 13 preguntas de negocio con funciones condicionales (CONTAR.SI.CONJUNTO, PROMEDIO.SI, INDICE/COINCIDIR) y tablas dinámicas conectadas a segmentadores. El dashboard final cruza producción, costos, consumo energético y emisiones por región, mineral y tecnología de extracción, identificando que la región Norte lidera en producción pero también en costos, y que la tecnología Avanzada reduce las emisiones por empleado frente a la Mixta.

**Tecnologías:** Excel avanzado · Tablas dinámicas · Funciones condicionales
**Archivo:** [Descargar Excel →](archivos/Analisis-Produccion-Minera.xlsx)

### 🌐 Estudio Factor — Sitio web de fotografía y producción audiovisual
Sitio web de 5 páginas para un estudio de fotografía y producción audiovisual, con copy propio, SEO on-page (meta description y Open Graph en cada página) y galería de imágenes con lightbox interactivo desarrollado en JavaScript. Incluye secciones de matrimonios, sesiones exteriores, arriendo de estudio/equipos y un formulario de contacto — todo con diseño responsive.

**Tecnologías:** HTML5 · CSS3 · JavaScript · SEO on-page · Responsive Design
**Demo:** [Abrir Sitio →](https://ruthtorresreyes.github.io/estudio-factor/)

## 🚀 Cómo verlo localmente

1. Clona el repositorio:
   ```bash
   git clone https://github.com/RuthTorresReyes/PortafolioRuthTorres.git
   ```
2. Entra a la carpeta del proyecto:
   ```bash
   cd PortafolioRuthTorres
   ```
3. Abre `index.html` en tu navegador (o usa una extensión tipo "Live Server").
